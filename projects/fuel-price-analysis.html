UK Fuel Prices Analysis and Prediction

code View on GitHub info Data Science Notebook (No Live Demo)

Overview

This project analyzes weekly UK fuel price data from 2003 to the present, examining trends in petrol versus diesel pricing and the relationships between pump prices, duty rates, and VAT. It follows a full, reproducible data science workflow, including data preprocessing, exploratory data analysis, feature engineering, and evaluating machine learning models.

Key Highlights

  • Feature engineering from timestamps to capture seasonal variations.
  • Comprehensive correlation heatmaps and feature importance plots.
  • Robust model evaluation using MAE, RMSE, and R² scores.

My Role

Team project — I implemented the data visualizations and performed the statistical analysis.

Tech Stack

Python Pandas scikit-learn Linear Regression Decision Tree Random Forest
